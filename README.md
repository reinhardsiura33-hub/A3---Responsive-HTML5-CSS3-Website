# A3 - Responsive HTML5 + CSS3 Website

## Project Purpose
This project is a modern, fully responsive website built using semantic HTML5 and advanced CSS3 styling. The website adapts seamlessly across various screen sizes (mobile, tablet, and desktop) to provide an optimal user experience.

## Features
* **Fully Responsive Design:** Utilizes CSS Media Queries and flexible layouts (Flexbox / CSS Grid) to scale across viewports.
* **Semantic HTML5 Structure:** Built with clean, accessible semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
* **Modern CSS3 Styling:** Features custom styling, smooth transitions, and a cohesive color palette.
* **Interactive Elements:** Includes responsive navigation and hover effects for enhanced UI/UX.

## Technologies Used
* **HTML5** (Semantic markup)
* **CSS3** (Flexbox, Grid, Media Queries, Custom Properties)
* **Git & GitHub** (Version control and repository hosting)

**AI Use Declaration**:
Artificial Intelligence tools were utilized during the development of this project to assist with:
Structuring semantic HTML5 layouts and writing initial CSS media queries.
Troubleshooting responsive grid alignment and debugging CSS flexbox wrapping behaviors.
Drafting documentation and structuring the project README.md.
All code was reviewed, tested, and integrated manually to ensure compliance with project specifications.
